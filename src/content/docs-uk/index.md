## Що таке LastMenu?

**LastMenu** — це повна бібліотека UI для FiveM. Вона об'єднує всі поширені типи меню (контекстне, радіальне, форма введення, сповіщення, повідомлення, індикатор прогресу, target) під **послідовним API builder**, без необхідності `ox_lib`, `qbx_core` чи будь-якого іншого фреймворку.

UI Svelte 5 **попередньо скомпільована** в `ui/assets/` — ніякого `npm install` не потрібно на стороні ігрового сервера.

## Чому LastMenu?

| Поширена проблема | Рішення |
|---|---|
| Залежність від `ox_lib` чи фреймворку | Нуль залежностей під час виконання |
| Різні API для кожного типу меню | Один паттерн builder для всього |
| Немає реактивності — закрити/відкрити для оновлення | Вбудований реактивний механізм опитування |
| Прив'язаний до фреймворку (ESX / QBCore) | Працює в будь-якому середовищі |
