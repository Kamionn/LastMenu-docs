## LastMenu이란 무엇인가?

**LastMenu**는 FiveM용 완전한 UI 라이브러리입니다. 모든 일반적인 메뉴 유형(컨텍스트, 방사형, 입력 양식, 경고, 알림, 진행률 바, 타겟)을 **일관된 빌더 API** 아래에 통합하며, `ox_lib`, `qbx_core` 또는 다른 프레임워크가 필요하지 않습니다.

Svelte 5 UI는 `ui/assets/`에서 **사전 컴파일**됩니다 — 게임 서버 측에서 `npm install`이 필요하지 않습니다.

## 왜 LastMenu인가?

| 일반적인 문제 | 해결책 |
|---|---|
| `ox_lib` 또는 프레임워크에 대한 종속성 | 런타임 종속성 제로 |
| 메뉴 유형별로 다른 API | 모든 것에 하나의 빌더 패턴 |
| 반응성 없음 — 업데이트를 위해 닫고 열기 | 통합된 반응형 폴링 엔진 |
| 프레임워크에 잠김 (ESX / QBCore) | 모든 환경에서 작동 |
