## Что такое LastMenu?

**LastMenu** — это полная библиотека UI для FiveM. Она объединяет все распространенные типы меню (контекстное, радиальное, форма ввода, оповещение, уведомление, индикатор прогресса, цель) под **последовательным API builder**, без необходимости `ox_lib`, `qbx_core` или любого другого фреймворка.

UI Svelte 5 **предварительно скомпилирована** в `ui/assets/` — никакого `npm install` не требуется со стороны игрового сервера.

## Почему LastMenu?

| Распространенная проблема | Решение |
|---|---|
| Зависимость от `ox_lib` или фреймворка | Ноль зависимостей во время выполнения |
| Разные API для каждого типа меню | Один паттерн builder для всего |
| Нет реактивности — закрыть/открыть для обновления | Встроенный реактивный механизм опроса |
| Привязан к фреймворку (ESX / QBCore) | Работает в любой среде |
