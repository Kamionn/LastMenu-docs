## LastMenu とは何ですか？

**LastMenu** は FiveM 用の完全な UI ライブラリです。すべての一般的なメニュー タイプ (コンテキスト、ラジアル、入力フォーム、アラート、通知、プログレス バー、ターゲット) を **一貫したビルダー API** の下に統合し、`ox_lib`、`qbx_core`、または他のフレームワークを必要としません。

Svelte 5 UI は `ui/assets/` で**事前コンパイル**されています — ゲーム サーバー側で `npm install` は必要ありません。

## なぜ LastMenu なのか？

| 一般的な問題 | 解決策 |
|---|---|
| `ox_lib` またはフレームワークへの依存 | ランタイム依存ゼロ |
| メニュー タイプごとに異なる API | すべてに 1 つのビルダー パターン |
| リアクティブ性なし — 更新のために閉じて開く | 統合されたリアクティブ ポーリング エンジン |
| フレームワークにロック (ESX / QBCore) | あらゆる環境で動作 |
